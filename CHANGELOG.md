# История изменений

В этом файле перечисляются выполненные изменения. Запланированные функции находятся в [дорожной карте](docs/ROADMAP.md).

## Unreleased

### 2026-10-14 — утверждение дизайна (решение 001)

- Принято решение 001: для приложения зафиксированы компоновка Studio (просторный центр обслуживания с верхней навигацией и единым рядом метрик) и цветовая палитра Жемчуг (Pearl: `#171819` / `#2a2c2f` / `#e0e3e9`).
- Цветовые токены, шрифты и геометрия зафиксированы в `docs/decisions/001-design-direction-studio-pearl.md` для реализации на этапе 1 (модули 1.3/1.4).

### 2026-10-14 — завершение этапа 0 (модули 0.3–0.5)

- Разработан и запущен автоматический валидатор целостности репозитория `scripts/check_docs.py` (проверены 30 файлов, 94 ссылки, 31 таблица, согласованность 54 модулей и отсутствие циклов).
- Закреплён стабильный Rust toolchain в `rust-toolchain.toml` (1.95.0, MSVC target, rustfmt, clippy).
- Создана конфигурация GitHub Actions CI `.github/workflows/ci.yml` для автоматической проверки целостности на Windows и сборки будущих модулей.
- Подтверждена работа `pnpm@12` в пользовательском режиме без elevation через npx/corepack, обновлено руководство по разработке.
- Закрыты все критерии приёмки модулей 0.3, 0.4 и 0.5; этап 0 дорожной карты завершён полностью.

### 2026-10-14 — пять палитр Studio

- Добавлены Янтарь, Мята, Ледник, Роза и Жемчуг с одинаковой компоновкой Studio.
- Добавлены переключатель палитр, отдельные URL, пять полных превью и общая галерея.
- Проверены мобильное переполнение и контраст основных цветовых пар. Выбор палитры остаётся за пользователем.

### 2026-10-14 — варианты интерфейса

- Подготовлены три отдельные композиции CleanCore: Control, Studio и Signal, с общим интерактивным HTML-просмотром.
- Добавлены desktop-превью, переключение страниц и состояния элементов без выдуманных метрик или файловых операций.
- Направление дизайна ожидает выбора пользователя. Продуктовые модули не отмечены завершёнными.

### 2026-10-14 — Git и GitHub

- Создан локальный репозиторий с основной веткой `main`.
- Создан публичный репозиторий https://github.com/dvd-bolt/cleancore и подключён `origin`.
- Подготовленный комплект сохранён первым коммитом и отправлен на GitHub.
- Обновлены статус и отметки модулей 0.1/0.2; продуктовая реализация ещё не начата.
