# CleanCore

Бесплатное приложение для мониторинга и обслуживания Windows. Планируется русский интерфейс, тёмная тема и локальная работа без телеметрии.

**Текущее состояние: подготовлены требования, дорожная карта и материалы для разработки. Созданы локальный Git и публичный [GitHub-репозиторий](https://github.com/dvd-bolt/cleancore). Исходного кода приложения и сборки пока нет.**

## С чего начать

1. Прочитать [правила работы](AGENTS.md) и [техническое задание](TECHNICAL_SPEC.md).
2. Посмотреть [дорожную карту](docs/ROADMAP.md), [задачи](docs/TASKS.md) и [текущий статус](docs/STATUS.md).
3. Перед реализацией изучить [архитектуру](docs/ARCHITECTURE.md), [контракты](docs/API_CONTRACTS.md) и [подготовку окружения](docs/DEVELOPMENT.md).
4. Выполнять по одному модулю, проверять результат и обновлять задачи и статус.

Первый цикл разработки — этапы 0–2: основа, окно приложения и мониторинг. Наличие этапа в плане не означает разрешения реализовать весь продукт за одну задачу.

## Будущий стек

Rust stable, Tauri 2, React, TypeScript, Vite и SQLite. Версии фиксируются при создании каркаса. Целевая ОС — Windows 10 x64; стабильный выпуск также проверяется на Windows 11 x64.

Команд запуска пока нет: `Cargo.toml` и `package.json` ещё не созданы. Не устанавливайте зависимости для выполнения примеров документации.

## Основные ограничения

- Обычные права пользователя, без универсального выполнения PowerShell/cmd.
- Реальные показатели; недоступные данные отображаются как «нет данных».
- Очистка: scan → preview → выбор → подтверждение → повторная проверка → execute → журнал.
- При сомнении объект пропускается. Автоматического удаления дубликатов нет.
- ИИ подключается позднее и не получает полномочий изменять систему.
