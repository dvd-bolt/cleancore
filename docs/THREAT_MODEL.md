# Модель угроз

Статус: модель угроз; реализованные меры и Windows fixture описаны в [отчёте](reports/STAGES1_7.md). Безопасная операция Корзины и полная матрица выпуска не приняты.

## Активы и границы доверия

Активы: пользовательские файлы, настройки системы, журнал действий и персональные сведения. Backend не доверяет входу webview, путям, переменным окружения и актуальности результатов scan. Открытый репозиторий и известная библиотека не являются гарантией безопасности.

## Угрозы

| Угроза | Последствие | Защита | Проверка |
| --- | --- | --- | --- |
| Traversal и строковый обход корня | Действие вне категории | Backend определяет корень; проверка объектов и компонентов пути | Относительные пути, `..`, похожие префиксы |
| Junction, symlink, reparse point | Перенаправление к чужой цели | Пропуск, включая родительские компоненты | Ссылки в корне и по пути |
| Замена после scan/проверки | Обработка другого объекта | Идентичность, дескрипторы и доказанные гарантии конкретной операции | Подмена файла и родителя в контролируемый момент |
| Hard links | Ошибочный учёт и обработка общего объекта | Для первой категории пропуск | Несколько имён одного объекта |
| UNC, device paths, ADS | Неожиданная семантика объекта | Первая категория ограничена поддерживаемой локальной файловой системой | Сетевые пути, устройства, alternate streams |
| Изменённый TEMP | Уход за безопасные границы | Не считать переменную окружения доказательством допустимости | Перенаправленный корень |
| Файл занят/недоступен | Потеря данных активной программы | Консервативная проверка; пропуск без обхода | Sharing modes, memory mapping, ACL |
| Повторный запрос | Повторное изменение | Связь с preview, lifecycle операции | Повторное подтверждение/исполнение |
| Компрометация frontend | Злоупотребление командами | Узкие разрешения и проверки Rust, CSP | Вызов из запрещённого окна, поддельные IDs |
| Падение/отказ SQLite | Потеря достоверного журнала | Намерение до действия, результат после, неизвестный исход | Ошибка записи и аварийное завершение |
| Огромное дерево/список | Нехватка памяти и зависание | Порции, лимиты и отмена | Большое тестовое дерево |
| Сторонний код | Уязвимость или лицензионный конфликт | Ревизии, аудит файлов и зависимостей | Реестр происхождения и проверки CI |
| Локальная модель | Утечка контекста и неверная рекомендация | Ограниченные сводки, отсутствие команд записи | Подмена контекста и попытка исполнения |

## Остаточные риски

- Обычные права ограничивают ущерб, но не защищают все файлы пользователя от ошибочного действия.
- Проверка непосредственно перед действием сама по себе не исключает race condition.
- Корзина может использовать обращение по пути; требуется анализ конкретного механизма и подтверждение гарантий. Если безопасное действие недоступно, исполнение пропускается или выпуск блокируется.
- Возраст временного файла не доказывает, что файл больше не нужен.
- Процесс, имеющий те же права пользователя и доступ к данным CleanCore, может вмешиваться в них. Журнал не позиционируется как защищённый криминалистический источник.

## Условия допуска исполнителя

Описание пути до действия, тип файловой системы, используемые Windows API, способ проверки занятого файла и контролируемые тесты подмены должны быть задокументированы до включения модуля 4.3. Без доказательства гарантий не объявлять исполнение безопасным.

Тесты создают собственные объекты в изолированном каталоге и не изменяют реальные пользовательские данные.

## Повышенный запуск и raw MFT

[Решение 006](decisions/006-elevated-mft-analysis.md) расширяет доверенную границу до повышенного процесса. NTFS metadata считаются недоверенными: bounds/fixup/sequence checks, лимит индекса и диагностика частичного результата. Снимок работающего тома может меняться. Raw handle только read, не передаётся в cleanup. Защищённое размещение повышенного exe/ресурсов, контекст дочернего ИИ и Windows acceptance требуют проверки до релиза.
