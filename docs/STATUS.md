## Реализовано на Этапе 5

- **5.1 Обход каталогов**: Создан новый крейт `cleaner-disk`. Реализован отменяемый потоковый обход файловой системы (`analyze_directory_tree`) с поддержкой отмены через `AtomicBool`, пропуском точек повторной обработки (`reparse points`, junctions, symlinks) и безопасной обработкой ошибок доступа без аварийных падений.
- **5.2 Крупные объекты**: Подсчёт размеров файлов и папок, сортировка крупнейших потребителей дискового пространства (`largest_files`, `largest_dirs`), вычисление процентных долей от исследуемого каталога.
- **5.3 Карта диска**: Распределение объёма по 7 категориям (Видео, Изображения, Документы, Архивы, Аудио, Код, Прочее). В React UI (`DiskPage.tsx`) отрисована многоцветная адаптивная полоса категорийного спектра и сетка карточек с объёмами, долями и счётчиками файлов.
- **5.4 Дубликаты (Czkawka 3-Phase Logic)**: Трёхфазный поиск идентичного содержимого:
  1. *Фаза 1*: Группировка файлов по абсолютно точному размеру в байтах (файлы с уникальным размером отсекаются сразу).
  2. *Фаза 2*: Вычисление прехеша (первые 16 КБ) с алгоритмом SHA-256.
  3. *Фаза 3*: Вычисление полного SHA-256 хеша для кандидатов с одинаковым прехешем.
  - *Защита Hard links*: Одинаковые физические файлы на NTFS/Windows (`GetFileInformationByHandle`: одинаковый `dwVolumeSerialNumber` и индекс файла `nFileIndex`) исключаются и не объявляются дубликатами.
  - *Защита TOCTOU*: Проверка неизменности времени модификации `mtime` до и после чтения хеша.
  - *Безопасность*: **Режим инспекции — автоматическое удаление отключено**, совпадающие имена или прехеши не объявляются дубликатами.
- **5.5 История ресурсов**: Кольцевой буфер `ResourceHistoryTracker` в оперативной памяти бэкенда на 600 замеров (10 минут). Непрерывная фиксация метрик CPU, RAM и сети (RX/TX) с визуализацией трендов (SVG-графики мин/ср/макс) на вкладке «История» в `DiskPage.tsx`.
- **5.6 Производительность и UI**: Быстрый выбор стандартных пользовательских папок (`QuickDirectory`: Профиль, Загрузки, Документы, Рабочий стол, Изображения, Видео, Музыка). Управление фоновыми задачами через `DiskManager`, опрос статуса через IPC без блокировки пользовательского интерфейса Tauri. Подробности: [отчёт этапа 5](reports/STAGE5.md).
