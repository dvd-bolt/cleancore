# Текущий статус

Обновлено: 2026-10-14.

## Что готово

- **Этап 0:** Полный комплект документации, спецификации, модель угроз, дорожная карта, лицензия MIT, Git/GitHub, Windows CI workflow, дизайн-решение 001 (Studio Pearl).
- **Этап 1 (v0.0.1):** Рабочий каркас desktop-приложения:
  - Rust workspace с крейтом `crates/cleaner-core` (типизированные DTO, ошибки, PathGuard, события).
  - Tauri 2 оболочка `src-tauri` (`cleancore.exe`, IPC-команды, default capabilities, CSP).
  - React 19 + TypeScript + Vite frontend в дизайне Studio Pearl (`src/`).
  - 5 экранов: Обзор, Процессы, Очистка, Журнал, Настройки.
- **Этап 2 (v0.0.2) — «Полезный монитор»:** Полностью реализованы модули 2.1–2.6:
  - Крейт `crates/cleaner-system`:
    - Модуль 2.1: Адаптер `SystemCollector` на базе `sysinfo 0.33.1` (CPU, RAM). Честный статус `FieldValue::NotMeasured` на первом замере CPU без подмены нулями.
    - Модуль 2.2: Сбор сведений о процессах (PID, имя, CPU %, RSS память, путь). CPU нормирован делением на количество ядер к общей шкале 0..100%. Защищённые процессы Windows возвращают `FieldValue::AccessDenied`. Полный запрет на команды завершения процессов.
    - Модуль 2.3: Опрос локальных накопителей (диски), ограниченный частотой раз в 30 секунд.
    - Модуль 2.4: Счётчики сетевых интерфейсов, вычисление скорости (байт/с) через монотонные часы `Instant`, защита от сброса счётчиков ОС через `saturating_sub`.
  - Крейт `crates/cleaner-storage`:
    - Модуль 2.6: Хранилище настроек SQLite (`StorageManager`) в `%LOCALAPPDATA%\CleanCore\cleancore.db` (с безопасным fallback на in-memory). Валидация интервалов (500..60000 мс).
  - Оболочка `src-tauri`:
    - Модуль 2.5: Неблокирующий фоновый поток мониторинга с отправкой событий `metrics-update` в окно, поддержка паузы, защита от наложения запросов через `try_lock()`.
  - Frontend (`src/`):
    - Живые метрики CPU/RAM/Диск/Сеть на странице «Обзор».
    - Динамический SVG-график активности в стиле Studio Pearl (`ActivityChart`) для CPU, RAM и Сети.
    - Полноценная страница «Процессы» (`ProcessesPage`): поиск по имени, PID и пути, сортировка по колонкам, бейджи для системных процессов с ограниченным доступом Windows, индикатор количества процессов.
    - Мини-таблица топ-процессов на главной странице.
    - Настройки интервала опроса (2, 5, 10 сек) с мгновенным сохранением в SQLite.
    - Кнопка паузы в шапке окна.
