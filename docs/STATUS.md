## Модули оптимизации CleanCore (OPT-01 – OPT-06) — 2026-10-16

Полностью реализованы все 6 модулей оптимизации и адаптивного управления ресурсами:
- **OPT-01 (Battery & AC Awareness):** Win32 `GetSystemPowerStatus`, индикатор питания и процента заряда в Header, power-aware троттлинг фоновых задач.
- **OPT-02 (Space Hogs):** Мгновенная выборка крупных файлов тома из MFT-индекса без повторного дискового ввода-вывода, фильтрация по категориям (образы, архивы, медиа, exe), исключение заблокированных файлов ОС, переход в Проводник.
- **OPT-03 (Stale Files):** Сканирование забытых файлов в каталогах Downloads/Desktop по порогам давности (30–730 дней), защита от репарсов и исключение служебных файлов.
- **OPT-04 (Dev Caches & System Recycle Bin):** Безопасный Win32 `SHQueryRecycleBinW` и `SHEmptyRecycleBinW` с 2-шаговым подтверждением; поиск неактивных `node_modules`, `target`, `.venv` и виртуальных дисков WSL/Docker `ext4.vhdx`.
- **OPT-05 (Power Profiles & SQLite Rollback Journal):** Профили электропитания и процессорный троттлинг (Тихий 99% без турбобуста, Баланс, Турбо 100%), транзакционный снимок и надёжный откат через SQLite.
- **OPT-06 (Auto-Pilot Watcher & Smart Insights):** Детектор нагрузки компиляторов/IDE, виджет персонализированных рекомендаций `SmartInsightsWidget` на главной странице `OverviewPage` с прямым переходом к инструментам.
- Проверки: 75 тестов Vitest, 25 тестов cleaner-disk, 44 теста cleaner-service, 16 тестов cleaner-storage, 9 тестов cleaner-system, 18 тестов cleancore_lib пройдены. `cargo clippy`, `cargo fmt --check`, `npm run build` и `python scripts/check_docs.py` завершены успешно. [Отчёт](reports/OPTIMIZATION_MODULES_2026_10_16.md).

## Расширение 2026-10-15: MFT и UAC

По прямому запросу пользователя основной exe требует администратора (requireAdministrator). Новый Rust NTFS MFT parser/index подключён к анализу корня диска; просмотр подпапок использует сохранённый индекс. Обычный обход остаётся для остальных случаев, с явной причиной fallback. [Решение 006](decisions/006-elevated-mft-analysis.md).

Реальный C: прочитан: первый проход 24,091 с; повторный одновременно со сборкой 44,169 с, 2 035 835 файлов / 475 116 каталогов, diagnostics пуст. Контролируемая папка: 2 файла, точно 123461 байт. Наблюдаемый peak working set повторного probe 1 268 510 720 байт. Эти замеры не являются сравнением с WizTree. Учёт unnamed DATA, hard links один раз; named streams исключены с предупреждением.

Parser/tree: 18 Rust tests, frontend: 42 tests, cargo check cleancore. Финальная release-сборка готова; приложение запущено, окно отвечает, TokenElevation=1 проверен. Визуальная автоматизация недоступна из-за ошибки node_repl; Windows 10/11 и WizTree comparison открыты. [Отчёт](reports/MFT_2026_10_15.md).

StartupApproved отвергаются. По выбору пользователя установлена иконка-кристалл в жемчужно-серой палитре темы: SVG, ICO и UI.
