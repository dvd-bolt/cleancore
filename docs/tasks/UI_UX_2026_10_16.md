# Задача — UI/UX восьми разделов, 2026-10-16

Статус: реализовано; автоматические проверки пройдены, визуальная приёмка частичная.

## Цель

Выполнить согласованный пользователем мини-план: сохранить Pearl, сделать
статус очистки постоянно видимым, улучшить читаемость и поведение экранов.

## Контекст

- Область: frontend всех восьми разделов по явному запросу пользователя.
- Интеграция: общий UI, навигация и один штатный диалог выбора папки Tauri.
- Backend удаления, анализа, мониторинга и хранилища не изменяется.
- Основание: TECHNICAL_SPEC, решение 001; ограничения выполнения сохраняются.

## Безопасность и сторонние компоненты

Только существующие зависимости, без заимствованного кода. Новая команда возвращает
путь из штатного диалога Windows и не запускает операции с этим путём. Тесты
интерфейса используют фикстуры и не удаляют реальные файлы.
