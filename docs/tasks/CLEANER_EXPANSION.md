# Задача CLN-01/03/04/05/07/08 — расширение очистки

Статус: реализованы основные локальные сценарии; весь план не завершён.

## Цель

Продолжать анализ больших категорий, чистить выбранные кеши, удалять выбранные объекты с карты и копии с сохранением оригинала. Проверять на собственных файлах без удаления пользовательских данных во время разработки.

## Контекст

- Требования и очереди: [план](../CLEANER_IMPLEMENTATION_PLAN.md), модули ROADMAP 3.x/4.x/5.x, [решение 007](../decisions/007-cleanup-batches-and-manual-selection.md).
- Зависимости: существующий BoundDelete, журнал, Known Folders, MFT reference и Canvas-карта.
- Границы: по новому запросу пользователя cleanup/core/execution/storage/disk, узкие Tauri-команды, CleanupPage, DiskPage и настройки. Остальные изменённые файлы не откатывать.

## Изменения

- [x] Порции, продолжение, готовые партии и отзыв токенов.
- [x] 11 правил, обнаружение профилей, возраст, последствия и отсутствие процесса браузера.
- [x] Ручные файлы/небольшие папки через общий исполнитель.
- [x] Выбор оригинала и копий, повторный полный SHA-256 под удерживаемыми handles.
- [x] Постоянные исключения, защищённые папки и ограниченный кеш хешей.
- [x] Обработка ошибок, устаревание отчётов и новые UI-тесты.
- [x] Документация/контракты и отчёт.
- [x] Ограниченный read-only анализ возможных остатков после штатного удаления.
- [ ] Корзина, категории приватности, удаление остатков и полная матрица выпуска.

## Безопасность и сторонние компоненты

Нет новых shell-команд или фоновой сети. Повышенные права уже действуют по решению 006. Все автоматизированные изменения файлов — собственные фикстуры. TOML-манифесты разбираются существующей locked версией toml; лицензия прочитана, запись — в REUSE. Код/определения BleachBit/Winapp2 не копировались.
