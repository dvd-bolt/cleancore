# Задачи CleanCore

Источник этапов и модулей — [ROADMAP](ROADMAP.md). Здесь ведутся отметки выполнения; краткая сводка — в [STATUS](STATUS.md).

В плане 54 модуля. Модули этапов 0 и 1 (10 модулей: 0.1–0.5 и 1.1–1.5) полностью выполнены; остальные 44 модуля (этапы 2–8) запланированы. Каркас первого приложения v0.0.1 успешно создан и протестирован.

## Правила

- `[ ]` — запланировано или не завершено; `[x]` — реализовано и проверено. Для работы/блокера добавить явную текстовую отметку в задачу и STATUS.
- Перед модулем выполнить зависимости и критерии предыдущего продуктового этапа. Блокер GitHub-публикации фиксировать отдельно; он не препятствует локальной разработке.
- Номер модуля — постоянный ID, не обязательный порядок: задачи 3.4 и 4.4 выполняются до сканера и исполнителя соответственно.
- Документы для 0.3/0.4 уже подготовлены; проверка и фиксация в Git выполняются после создания репозитория.
- Для каждого модуля необходимы применимые проверки из [TESTING](TESTING.md), ограничения и [отчёт](templates/REPORT.md).
- Не расширять текущий запрос пользователя на весь план.
