# Отчёт по этапу 8 и повторным проверкам

Дата: 2026-10-14. Статус: компоненты реализованы, полная приёмка открыта.

## Результат

Добавлен локальный помощник с ручным выбором GGUF, подтверждением лицензии весов,
выбором данных и предварительной сводкой. Запускается закреплённый CPU runtime
llama.cpp без HTTP endpoint, облака, загрузки весов и команд изменения системы.
Вопрос и сводка идут по stdin, ответ отображается обычным текстом. Можно остановить
запрос или отключить модель. Основные функции доступны без неё.

Новая категория user-temp-logs-v1 показывает .log старше 30 суток в пользовательском
Temp. Отдельные правила и Windows fixture; категория не создаёт execution-token.

## Изменения

cleaner-assistant: bounded GGUF metadata parser и удержание файла; согласие для
конкретного ID; ограниченный выбранный контекст с TTL; process guard, Windows Job,
лимиты/таймаут/отмена. Tauri принимает ID и выбор агрегатов, не runtime paths/flags.
AssistantPage: состояния без модели, просмотр данных, вопрос, текстовый ответ,
типизированная ручная навигация. Состав runtime закреплён манифестом SHA-256;
MIT/LLVM OpenMP лицензии включены в поставку и notices.

Архитектура и ограничения: [решение 004](../decisions/004-local-assistant.md),
[API](../API_CONTRACTS.md), [правила](../CLEANUP_RULES.md), [REUSE](../REUSE.md).

## Риски и остаток

GGUF-файл не предоставлен. Нельзя подтвердить качество русских объяснений, успешный
инференс, отмену на реальной генерации и измеренные пределы RAM/CPU. Заданы защитные
лимиты, но они не заменяют эти испытания. Указанный список архитектур — допустимые
метаданные, не матрица протестированных моделей. Веса следует брать из доверенного
источника; нативный процесс не является AppContainer.

Сохраняются блокеры предыдущего [аудита 1–7](STAGES1_7.md): безопасная production
Корзина 4.3, большие отчёты диска 5.6, приёмка деинсталляторов, Windows 10/11 VM,
установка/обновление/удаление, масштаб и soak, аудит зависимостей/лицензий.
Версия 0.0.3 — кандидат, публикации нет. Release gate блокирует выпуск и теперь
требует отдельное свидетельство local_assistant_real_model.
