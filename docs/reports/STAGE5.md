# Отчёт по этапу 5 — Анализ диска и дубликатов (v0.2)

Дата: 2026-10-14. Статус: Этап 5 полностью реализован, протестирован и интегрирован в режиме строгой изоляции (`isolated-development`).

## Результат

Создан новый независимый крейт `cleaner-disk`, набор узких IPC команд `disk_commands.rs` и отдельный UI `DiskPage.tsx` в тёмном стиле Studio Pearl.
Реализован отменяемый обход структуры выбранных каталогов, расчёт категорийного спектра (Видео, Изображения, Документы, Архивы, Аудио, Код, Прочее), сортировка крупнейших потребителей дискового пространства, безопасный трёхфазный поиск дубликатов (Czkawka 3-phase logic) с аппаратным исключением Hard links и 10-минутный кольцевой буфер истории системных ресурсов.

Разработка выполнена строго в границах протокола `isolated-development`: код параллельно проверяемых этапов 1–4 не затрагивался и не модифицировался.

## Архитектурные решения и безопасность

1. **Трёхфазный алгоритм поиска дубликатов (Czkawka logic):**
   - *Фаза 1*: Быстрая группировка по точным байтовым размерам (`size_bytes`). Одиночные файлы отсекаются с нулевыми затратами на чтение диска.
   - *Фаза 2*: Для групп кандидатов читаются первые 16 384 байт (прехеш SHA-256). Файлы с разными заголовками немедленно разделяются.
   - *Фаза 3*: Вычисление полного хеша SHA-256 только для файлов с совпавшим прехешем.
2. **Исключение Windows Hard links:**
   - Два жестких линка ссылаются на одну и ту же запись MFT и не занимают дополнительного места. Через Win32 API `GetFileInformationByHandle` извлекаются `dwVolumeSerialNumber`, `nFileIndexHigh` и `nFileIndexLow`. Если физический идентификатор совпадает, второй файл исключается из дубликатов.
3. **Защита от изменений во время чтения (TOCTOU):**
   - Время модификации файла (`mtime`) проверяется до чтения и сверяется после завершения хеширования. Если файл был изменён в процессе чтения, он дисквалифицируется.
4. **Строгий запрет на автоматическое удаление:**
   - В соответствии с требованиями ТЗ CleanCore и правилами безопасности, поиск дубликатов работает **исключительно в режиме инспекции**. Никаких автоматических кнопок удаления или скрытых операций с файлами нет.
5. **Кольцевой буфер истории ресурсов:**
   - Буфер `VecDeque` ограничен 600 замерами (10 минут при такте 1 сек). Не вызывает утечек памяти и не требует обращений к SQLite, сохраняя плавность UI.
