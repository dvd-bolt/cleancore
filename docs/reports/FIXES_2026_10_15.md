# Исправления по пользовательскому отчёту

Дата: 2026-10-15. Статус: локальные исправления и проверки.

## Результат

1. Анализ диска сохраняет доступный частичный отчёт вместо отказа всей задачи при
недоступной подпапке. Есть выбор локального диска целиком, причины пропусков,
страницы по 50 подпапок и переход внутрь. Завершённая задача восстанавливается при
переходе между разделами, terminal errors выводятся явно. Отмена сохраняет прочитанную часть.
Обход потоковый, лимиты 1 млн объектов/50 тыс. ожидающих каталогов/64 уровня; крупнейшие
файлы ограничены 20. Это не доказательство полного анализа или физически занятого места.

2. Очистка user-temp-v1 получает BoundDelete: только выбранные файлы от 7 суток,
неизменившиеся с scan; удаление БЕЗВОЗВРАТНО по проверенному эксклюзивному handle,
без Корзины, с отдельным предупреждением и подтверждением. Intent/result SQLite,
ошибки, пропуски и отмена сохраняются. Для Partial с недоступными подпапками требуется
дополнительное согласие; лимиты/отмена/fatal root запрещают исполнение.
Категория .log остаётся только анализом. [Решение 005](../decisions/005-bound-temp-deletion.md).

3. Автозагрузка: переключение только HKCU Run и StartupFolderUser с диалогом
подтверждения. IPC принимает ID/ожидаемую команду/согласие; свежий backend список
проверяется повторно. Меняется только 12-байтовая REG_BINARY отметка StartupApproved;
команда и файлы не удаляются и не запускаются. Неизвестные форматы отвергаются;
чётность 2/3 и 6/7 сохраняется. HKLM/RunOnce/common требуют штатного Диспетчера задач.
Формат StartupApproved не является документированным публичным контрактом Microsoft:
проверка Windows версий остаётся обязательной. Перезагрузка/вход не тестировались.

4. Собственная векторная иконка public/cleancore.svg: мятная C, светлое ядро,
тёмная плитка. Tauri CLI сгенерировал ICO/PNG/ICNS; знак подключён в заголовке.
Растровые AI-изображения и чужие логотипы не использовались.

## Проверки

Таргетированные Rust fixture покрывают partial disk, полный цикл удаления собственных
тестовых файлов, замену/занятость/родительские гонки и запись состояния автозапуска
только в Software/CleanCoreTests. Тесты интерфейса покрывают восстановление результата,
видимую terminal error и необратимое подтверждение. Финальные проверки:
- cargo test -p cleaner-disk -p cleaner-service -p cleaner-cleanup -p cleaner-execution -p cleaner-storage: 120 passed, 1 ignored, код 0.
- cargo test -p cleancore: 15 passed, код 0, включая local-main ACL и отсутствие изменения без согласия.
- cargo test -p cleaner-core -p cleaner-assistant -p cleaner-system --lib: 22 passed, 1 ignored, код 0.
- Всего в целевых прогонах: 157 passed, 0 failed, 2 ignored. Это не успешный cargo test --workspace.
- cargo test --workspace: код 1, OS 112 (недостаточно места при создании debug/cleancore_lib.lib); тестовых падений в этом прогоне не диагностировалось.
- cargo fmt --all --check и targeted Clippy --all-targets -D warnings: код 0.
- pnpm lint и pnpm test: код 0; 41 тест в 9 файлах.
- pnpm tauri build --config src-tauri/tauri.release.conf.json --no-bundle: код 0, production frontend и release exe собраны.
- python scripts/check_docs.py и git diff --check: код 0.

Ярлык Desktop/CleanCore.lnk указывает на новый release exe и новый icon.ico.
Внешний установщик повторно не упаковывался. Native окно показало новую иконку,
кнопку диска C: и работающий прогресс реального read-only анализа. Отмена анализа C: показала «Ниже сохранена прочитанная часть» и частичный отчёт; файлы не изменялись.

## Ограничения

Корзина не реализована. Это отдельный необратимый режим, а не скрытый fallback.
Не заявляется полная совместимость Windows 10/11 и чистая приёмка установки.
Сохраняются ограничения релиза/аудита из предыдущих отчётов; модель пользователь
добавит позже. Старый NSIS установщик не содержит этих исправлений — обновляется
прямой release exe и ярлык.

Попытка удалить только target/debug/incremental для места под сборку отклонена
автоматической проверкой («blocked by policy»). После явного разрешения пользователя повторная попытка отклонена с той же причиной. Кеш не удалялся, обхода отказа нет.
