# Отчёт: вложенная карта диска

Дата: 2026-10-15. Статус: реализовано, локальный release exe обновлён.

## Результат

По согласованному с пользователем плану добавлена вложенная прямоугольная карта в DiskPage под статистикой. Canvas рисует папки/файлы, площадь соответствует выбранному размеру, цвета зависят от расширений, мягкая подсветка помогает различать блоки. Список подпапок свёрнут ниже карты; прежние сводки/топ-файлы сохранены.

Наведение показывает путь/размер/долю. Щелчок выбирает объект и его сведения, двойной щелчок по папке приближает её, breadcrumbs и «Выше» возвращают назад. Имеются изменение высоты, развёрнутая область в AccessibleDialog с Escape, выбор logical/allocated, легенда для подсветки расширения, отдельный список первых 100 пустых файлов текущей папки. Контекстное меню и панель объекта: копирование пути и показать в Проводнике. Удаление/открытие содержимого/запуск файлов отсутствуют.

## Изменения

- cleaner-disk/ntfs/treemap: bounded projection из существующего immutable MFT index, максимум 12000 узлов и глубина 24, группы мелких объектов сохраняют весь размер. Легенда ограничена 128 строками; прочие расширения объединяются с точной суммой. Индекс не перечитывает диск для навигации.
- MFT API получает только действующий report ID/path/mode, выдаёт DTO дерева и empty-file list. Reveal получает report ID + opaque file reference, разрешает путь только в backend из текущего индекса.
- Native Reveal использует SHParseDisplayName / SHOpenFolderAndSelectItems и COM RAII; shell/ассоциация файла/переданный frontend путь не запускаются. Новые команды разрешены только main local capability.
- Геометрия и hit testing отделены от Canvas. Фон карты кэшируется: при наведении перерисовываются рамки поверх готового изображения. DTO не содержит миллионы отдельных объектов.
- Для обычного directory report строится явно подписанная сводная карта подпапок/прямых крупнейших файлов с группой остатка. Содержимое папок не выдумывается; подробная карта требует MFT, allocated/reveal для сводки недоступны.

## Риски и остаток

Визуальное соответствие/поведение мыши в настоящем WebView2 не подтверждено автоматизацией; требуется ручная проверка. Тест Canvas geometry не заменяет скриншот. Windows 10/11 acceptance и сравнение WizTree по прежнему открыты.

Группы и folder nodes без children обозначают предел детализации текущего масштаба. Вход в такую папку запрашивает её с новым бюджетом, но огромная папка с более 12000 прямыми элементами всё равно содержит группу остатка; UI сообщает это явно. Метаданные на работающем диске могут устареть; Reveal возвращает ошибку для исчезнувшего файла. Named streams/выбор одного hard-link пути сохраняют прежние правила MFT.

Полный workspace test в этом изменении не заявляется. Исполнитель очистки и сторонние модули не менялись. Новых внешних библиотек/заимствованного кода нет.
