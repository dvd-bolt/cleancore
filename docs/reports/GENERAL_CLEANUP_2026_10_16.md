# Очистка из результата общего анализа

Дата: 2026-10-16. Статус: реализовано, целевые проверки пройдены, release exe обновлён.

## Результат

После общего анализа доступны единый объём в МБ/ГБ, число уникальных исполнимых
кандидатов, выбор целых категорий или отдельных файлов и «Очистить выбранное».
Следующий экран фиксирует выбранные количество/объём и точный список с пагинацией.
Без явного согласия с безвозвратностью удаление не запускается.

Повторы по физическому идентификатору исключены. Категории только для анализа не
увеличивают исполнимый итог. У недоступной/ошибочной категории нет выбираемых
объектов. Частичный результат требует отдельного подтверждения; лимит 50 000
кандидатов подписан явно. Отменённый анализ исполнение не разрешает.

Общая очистка использует прежний исполнитель партиями до 1000 и существующий журнал.
Есть прогресс, остановка, количество удалённых/пропущенных/ошибочных файлов и объём
удалённых данных. Использованный список закрывается до нового анализа. При возврате
на экран общей очистки ID текущей операции читается из sessionStorage, фоновой
автоматической очистки при следующем запуске приложения нет.

## Изменения

- cleaner-cleanup/general.rs: bounded snapshot, дедупликация, точное одноразовое
  согласие, последовательный мастер партий, прогресс и отмена.
- TaskManager: сохранение доверенных идентичностей текущей партии и перенос до resume.
- cleaner-execution/native.rs: read-only getter полного физического идентификатора.
- Узкие IPC, permissions/capabilities для локального main.
- GeneralCleanupSelection и форматирование МБ/ГБ, страницы файлов и выбранного списка.
- Решение безопасности: [008](../decisions/008-general-cleanup-selection.md).

## Риски и остаток

Нативная проверка нового интерфейса в окне не выполнялась. Пользовательские файлы
не удалялись. Общий объём — оценка по логическим размерам, не замер прироста свободного
места. Корзина, приватные базы браузеров и другие открытые пункты прежнего плана
не объявляются реализованными. Общий снимок не атомарен, проверка повторяется при
действии. После полного перезапуска приложения — новый анализ, сведения начатых
партий остаются в «Журнале».
