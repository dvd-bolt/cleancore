## Изменения

- Полная сводка дисков и скоростей адаптеров; отсутствие данных не объявляется AccessDenied без доказательств.
- Убраны вымышленные browser-данные и успешные действия для этапов 5/6.
- История хранит null при недоступных замерах, ограничена монотонным окном 600 секунд и 1201 точкой;
  графики оставляют разрывы и не включают пропуски в статистику.
- DiskManager допускает одну активную задачу и хранит только текущий результат, отменяется при выходе.
  Анализ ограничен глубиной 32 и 100000 объектами, top файлов сохраняется ограниченным списком.
- BoundReader и DirectoryLease удерживают объекты при чтении; hard links, reparse и недоступные данные
  не обходятся. Фаза полного хеша сравнивает физическую идентичность и размер с предыдущей фазой,
  проверяет отмену между блоками. При превышении лимитов выдаётся ошибка вместо полного отчёта.
- System32 определяется Windows API; запуск EXE по PATH, скриптов и сетевых деинсталляторов запрещён.
  Не используется fallback QuietUninstallString. Устранён двойной учёт HKCU Uninstall в двух registry views.
  CPU диагностики получает два замера. Долгие команды чтения планируются вне UI-потока.
- Frontend больше не выбирает произвольный путь записи. Нативный диалог выбирает новый CSV;
  create_new не позволяет перезаписать существующий объект. Добавлен CSV последних 200 операций
  журнала (не более 10000 объектов) с тем же экранированием ячеек.
- Диалоги используют Radix, клавиатурный фокус виден, есть переход к основному содержимому,
  aria-current/pressed и reduced-motion. Длинные диалоги прокручиваются.
- Сохранение настроек сериализует запись и изменение памяти, временный файл создаётся эксклюзивно.
  Ошибки ввода-вывода не объявляются повреждением. Блокировка SQLite удерживается во время recovery,
  sidecars сохраняются в карантин. UI показывает фактические пути и recovery.
- Установщик для текущего пользователя с offline WebView2, подготовка notices при каждой сборке,
  закреплённые GitHub Actions и проверка обязательных свидетельств выпуска.

Начальная проверка Rust workspace и 32 frontend-теста прошли.
После исправлений frontend: 33 теста, включая DOM-тест имени диалога, удержания/возврата фокуса и Escape.
Rust fixture дополнены проверками hard links, совпадающего prehash при разных данных,
отмены хеширования, отказа перезаписи CSV, экранирования журнала и конкурентных настроек.
Один symlink-test ignored: требует Developer Mode/особых прав, повышение прав не выполнялось.

Native smoke выполнялся через computer-use на Windows 11 Pro 10.0.26200:
запуск release-бинарника с отдельными LOCALAPPDATA/APPDATA в artifacts/native-test,
реальные метрики и таблица процессов, переходы, чтение сервисного списка,
сохранение интервала 5000 мс на диск, проверка паузы (временная метка неизменна), восстановление интервала и паузы после перезапуска, возобновление, открытие/закрытие CSV-диалога по Escape и штатный выход. Нативный диалог сохранил новый journal-smoke.csv (107 байт с BOM и заголовком) в тестовый каталог; приложение показало путь и успех.
Персональные списки процессов/программ в репозиторий не сохранялись.
Это не испытания чистой установки и не доказательство совместимости Windows 10.

Первая попытка NSIS завершилась ошибкой os error 32: тестовый release-бинарник был запущен
до окончания упаковки. Экземпляр закрыт; повторная упаковка NSIS прошла. Для обычных проверок Cargo используется базовый конфиг без generated resources; release-конфиг отдельно подключает notices и лицензию.

устранило их. postcss-selector-parser закреплён на 7.1.6 через pnpm overrides.

RUSTSEC-2024-0429 (glib, транзитивная платформенная зависимость). Предупреждения не скрыты.
Инвентаризация дала 495 пакетов с исходными license/notice; 20 требуют отдельной проверки текста.
Workflow в GitHub и публикация не запускались.

## Риски и остаток

Главный блокер — 4.3: Windows Корзина должна обрабатывать тот же объект, который подтверждён
и повторно проверен. Закрытие handles с последующим удалением по пути эту гарантию нарушает.
DisabledRecycle оставлен; окончательное удаление и автоматическая очистка не добавлены.
Доступных чистых VM Windows 10/11 нет: установка без сети, смена версии и удаление
не выдаются за пройденные. Версия остаётся 0.0.3.
Полная матрица — [RELEASE](../RELEASE.md), решение — [003](../decisions/003-release-candidate.md).
