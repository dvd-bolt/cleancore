# NTFS MFT / повышенный запуск — 2026-10-15

## Запрос и результат

Пользователь явно потребовал основной exe с правами администратора и замену движка анализа на Rust MFT. Прежний запрет повышения заменён решением 006. Очищение/автозагрузка/ИИ не расширялись. Обновлённый exe собран по прежнему пути desktop-ярлыка; старый NSIS не перепакован.

Собственная реализация cleaner-disk/ntfs: read-only raw volume, NTFS 3.0/3.1, 4 MiB batches, fixup/границы/overflow, data runs, расширения $MFT mapping, объединение extension records, проверка sequence родителей, дерево и агрегация без рекурсии. Один MFT-индекс позволяет просматривать подпапки без нового чтения тома. Raw device path нельзя передать через UI: bootstrap принимает только обычный X:\.

Обновлены DTO/IPC/UI: engine, время, logical/allocated, volume used, причины fallback, diagnostics и отдельные warnings учёта. get_disk_analysis_report с path работает в spawn_blocking по текущему индексу и ID отчёта. Некорректный новый путь не уничтожает предыдущий backend-отчёт.

## Границы и остаток

Учитывается unnamed DATA. Hard links учтены один раз по выбранному имени; DOS alias не отдельный файл. Named streams исключены явно; internal NTFS metadata не полностью представлена DATA. Allocation resident=0, sparse/compressed берётся из TotalAllocated. Complete означает завершение поддерживаемого учёта, а не совпадение с Space Used Windows.

Оценочный бюджет 1 GiB / 4 млн активных записей выдаёт partial; RSS не ограничен жёстко. Ошибка MFT bootstrap включает обычный обход с причиной, его прежние лимиты и DirectoryLease остаются; отдельные папки без индекса не получают скорость MFT. Дубликаты по содержимому также остаются отдельным сканером.

Не приняты: WizTree comparison с одинаковыми правилами hard links/ADS, Windows 10/11 VM/UAC под другой учетной записью, огромные/сильно фрагментированные тома, полная ACL/reparse/soak матрица, защищённая установка повышенного приложения/ресурсов. Локальный помощник теперь наследует повышенный контекст; Job не снижает токен. GGUF по-прежнему не выбран. Эти ограничения не скрываются статусом сборки.
