# Подготовка и проверка выпуска CleanCore

Статус: кандидат для испытаний, версия 0.0.3. Готовность 1.0 не заявляется.
Обязательные незакрытые критерии: [матрица](release-acceptance.json), [отчёт](reports/STAGES1_7.md).

## Сборка кандидата

Windows x64, Visual Studio Build Tools с C++, Rust из rust-toolchain.toml, Node.js 24, pnpm 12.11.2 и Python 3.11+.

```powershell
pnpm install --frozen-lockfile
cargo test --workspace --locked
pnpm lint
pnpm test
pnpm tauri build --config src-tauri/tauri.release.conf.json --bundles nsis
```

Перед упаковкой автоматически выполняются frontend build и scripts/prepare_bundle.py:
снимается Windows x64 граф Cargo.lock, состав frontend из pnpm-lock.yaml, собираются
оригинальные LICENSE/NOTICE в artifacts/legal. Они включаются в каталог legal установщика.
Пакеты без текста лицензии перечислены в inventory.json: автоматическая генерация не заменяет проверку лицензий.

Результат: target/release/bundle/nsis/CleanCore_0.0.3_x64-setup.exe.
Не запускайте target/release/cleancore.exe во время пересборки/упаковки этого файла.
Установщик NSIS работает для текущего пользователя. WebView2 offlineInstaller включён;
загрузка runtime требуется на машине сборки, установка на целевой машине должна работать без сети.
Поведение WebView2 и отсутствие UAC на чистой машине ещё требуют проверки.
Основание конфигурации: [официальная документация Tauri](https://v2.tauri.app/distribute/windows-installer/).

## Ручное обновление и данные

Закройте приложение и сохраните резервную копию каталога %LOCALAPPDATA%\CleanCore.
Запустите установщик новой версии поверх прежней от того же пользователя.
Автоматического updater и фоновой проверки новых версий нет.
Идентификатор com.cleancore.app и каталог данных остаются стабильными.
Настройки хранятся в settings.json; журнал и legacy-настройки — в cleancore.db.
Миграции используют SQLite user_version; неизвестная будущая схема отвергается.
Откат старым установщиком не является обратной миграцией.

При повреждении исходные данные сохраняются в файлы .corrupt, включая sidecars SQLite;
ошибки доступа и блокировки не считаются повреждением. В разделе настроек видны пути,
версия схемы, режим памяти и сведения о восстановлении. До публичного выпуска нужно
проверить обновление и удаление на VM и зафиксировать политику сохранения пользовательских данных.

## Матрица приёмки

| Среда / сценарий | Требование | Состояние |
| --- | --- | --- |
| Windows 11 Pro, build 26200, текущая машина | Исторический запуск без elevation, монитор и навигация | Smoke до решения 006; новая UAC-приёмка отдельно; не чистая VM |
| Windows 10 22H2 x64 | Полный сценарий | Не проверено |
| Чистая Windows 11 x64 | Полный сценарий | Не проверено |
| Без сети, WebView2 отсутствует | Установка и первый запуск | Не проверено |
| Обновление предыдущей версии | Настройки и журнал сохранены | Fixture миграций пройдены; инсталлятор не проверен |
| Удаление приложения | Корректное удаление и политика данных | Не проверено |
| Масштаб 100/150/200% | Доступны навигация, таблицы и диалоги | Клавиатурный тест пройден; полная матрица не проверена |
| Длительная работа | Измеренные CPU, RAM, отмена, отсутствие накопления задач | Лимиты реализованы; длительные измерения не выполнены |

В evidence записываются ссылки на реальные отчёты, сборка ОС, версия кандидата и SHA-256.
Не изменяйте passed на true без испытаний соответствующего сценария.

## Выпуск и аудит

.github/workflows/release.yml собирает кандидат по workflow_dispatch или тегу v*.
GitHub Actions закреплены на commit SHA. Workflow формирует установщик, notices и SHA256SUMS.txt;
отдельная audit job проверяет зависимости и матрицу. Workflow пока не запускался в GitHub.
Публикация и автоматическая установка не выполняются. Черновик релиза готовится вручную
после устранения блокеров с приложением SHA-256, release notes и ограничений.

```powershell
cargo install cargo-audit --locked --version 0.22.1
cargo audit --deny warnings
pnpm audit --audit-level moderate
python scripts/check_release.py
```

Проверка scripts/check_release.py намеренно завершается с ошибкой, пока матрица открыта.
В инструментах сборки остаётся braces 3.0.3 (GHSA-vfj7-8cjw-p6xm), исправленной версии в реестре на момент проверки нет.
Rust audit не нашёл записей в vulnerabilities, но сообщил предупреждения glib и proc-macro-error.
Нельзя выдавать эти результаты за чистый аудит релиза.

## Дополнение этапа 8

Перед bundle scripts/prepare_assistant_runtime.py проверяет или загружает закреплённый
CPU runtime b11429; без готового runtime первая сборка требует сеть. Поставляемое
приложение не загружает модели/runtime. NSIS включает runtime/llama-b11429 с его
MIT/LLVM OpenMP лицензиями; GGUF в поставку не входит. Публичная приёмка требует
local_assistant_real_model в release-acceptance.json. [Отчёт 8](reports/STAGE8.md).
