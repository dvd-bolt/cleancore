# Безопасность и приватность

Статус: обязательные правила будущей реализации. Само наличие документа не подтверждает безопасность приложения.

## Привилегии

- Основной процесс работает с правами текущего пользователя.
- Access Denied — штатный исход с объяснением. Автоматического elevation нет.
- Нет универсального helper, произвольного выполнения PowerShell/cmd и драйвера ядра.
- Разрешения Tauri и собственных команд задаются явно и проверяются отрицательными тестами.
- Из UI нельзя передать новую произвольную цель удаления.

## Файловые операции

Следовать [CLEANUP_RULES](CLEANUP_RULES.md) и [THREAT_MODEL](THREAT_MODEL.md). Предварительный просмотр и повторная проверка обязательны. Строковая нормализация пути недостаточна для защиты от смены объекта.

Нельзя повышать права, менять ACL, завершать процесс или снимать защитные ограничения ради успешной очистки. Неопределённый объект пропускается. Отказ Корзины не разрешает окончательное удаление.

## Интерфейс

Ресурсы поставляются локально. Настроить CSP, запретить ненужную навигацию и доступ удалённого контента к backend. Системные имена и сообщения отображать как текст; не вставлять недоверенный HTML.

## Данные

- Нет телеметрии, аккаунта, аналитики и обязательного облачного соединения.
- Настройки и журнал находятся в локальном каталоге данных пользователя.
- Не хранить командные строки процессов, содержимое файлов, секреты и полные диагностические дампы без отдельной необходимости.
- Отличать историю действий от диагностических логов. Полные пути сохранять только при обоснованной необходимости.
- Очистка истории требует явного запроса и не выполняется во время активной операции очистки.
- Экспорт — только по запросу, с явным выбором файла.

Проверка трафика различает обращения CleanCore и фоновые действия Windows/WebView2. Установочные загрузки также учитываются в офлайн-сценарии.

## Зависимости и ИИ

Ревизии фиксируются, лицензии и уязвимости проверяются до включения. Следовать [REUSE](REUSE.md). Локальный ИИ получает только ограниченный контекст чтения и не имеет полномочий исполнения.

## Сообщения об уязвимостях

Публичный репозиторий — https://github.com/dvd-bolt/cleancore. Опубликованных версий приложения нет; приватный канал пока не подтверждён. Не указывать выдуманную почту или URL. Перед первым релизом настроить GitHub private vulnerability reporting и обновить этот раздел проверенным способом связи.

После появления приватного канала сообщать версию, ОС, воспроизводимый сценарий, ожидаемый и фактический результат без пользовательских секретов. Не публиковать чувствительные журналы в обычных issues.

## Поддержка

Список поддерживаемых версий появится после релиза. Пока продукта для эксплуатации нет. Поддержка приложения не заменяет обновления безопасности ОС.
