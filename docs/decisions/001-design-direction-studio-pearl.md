# Решение 001 — Дизайн интерфейса Studio (Жемчуг / Pearl)

Дата: 2026-10-14. Статус: принято.

## Контекст

Для этапа 1 (модули 1.3 «Интерфейс» и 1.4 «UI-компоненты») требовалось утвердить дизайн-направление, пространственную компоновку окон и цветовую палитру тёмной темы CleanCore.
В `docs/design/` были исследованы три концепта:
1. Control (классическая панель, боковая навигация, мятный акцент).
2. Studio (просторный центр обслуживания, верхняя навигация, единый ряд метрик, крупный блок очистки).
3. Signal (инструментальная панель, узкая навигация, график активности слева).
Для концепта Studio были протестированы пять цветовых палитр: Янтарь, Мята, Ледник, Роза, Жемчуг.

## Решение

Утверждены:
1. **Композиция:** **Studio** — просторный центр обслуживания:
   - Верхняя навигация с переключением разделов: Обзор, Процессы, Очистка, Журнал, Настройки.
   - Единая полоса ключевых показателей (CPU, RAM, Свободное место на диске, Сеть).
   - Интерактивный график активности в реальном времени с переключением метрик (CPU / RAM / Сеть).
   - Фокусная карточка очистки («Сначала посмотреть. Потом решить») со статусом безопасности.
   - Таблица предварительного просмотра процессов и индикатор локального режима («Только на твоём ПК · Без телеметрии»).
2. **Палитра:** **Жемчуг (Pearl)** — сдержанная монохромная графика с платиновым акцентом:
   - Фон окна (`--bg`): `#171819`
   - Оболочка (`--shell`): `#212325`
   - Основная поверхность карточек (`--surface`): `#2a2c2f`
   - Вторичная поверхность (`--surface-2`): `#36393d`
   - Разделительные линии (`--line`): `#484c52`
   - Основной текст (`--text`): `#f1f2f4`
   - Вторичный приглушённый текст (`--muted`): `#c1c4ca`
   - Вспомогательный текст (`--dim`): `#a6aab3`
   - Акцентный платиновый цвет (`--accent`): `#e0e3e9`
   - Текст на акценте (`--accent-ink`): `#25282e`
   - Полупрозрачная подсветка акцента (`--accent-wash`): `#35393f`
3. **Типографика:**
   - Заголовки: системный `Bahnschrift`, fallback `Trebuchet MS`, `sans-serif`.
   - Основной текст: `Trebuchet MS`, fallback `system-ui`, `sans-serif`.
   - Числа и идентификаторы: моноширинный `Cascadia Mono` / `Consolas`, `monospace`.

## Альтернативы

| Вариант | Преимущества | Цена / ограничения | Причина выбора или отказа |
| --- | --- | --- | --- |
| Studio (Жемчуг / Pearl) | Спокойный строгий технический стиль, высокий контраст (14.08:1 для текста, 11.49:1 для кнопок), просторная компоновка | Монохромность требует аккуратной расстановки иерархии | **Принято пользователем.** Обеспечивает профессиональный вид системного инструмента без лишнего визуального шума. |
| Studio (Янтарь / Amber) | Тёплый ретро-инженерный акцент | Золотистый оттенок может отвлекать от системных данных | Отклонено в пользу нейтрального Жемчуга. |
| Studio (Ледник / Glacier) | Холодный оттенок, классический для системного мониторинга | Чуть менее уникален | Рассмотрен, предпочтён Жемчуг. |
| Control (Мята) | Традиционный сайдбар слева | Меньше полезного горизонтального пространства для графиков и таблиц | Отклонено в пользу Studio. |
| Signal | Компактная колонка метрик, узкий тулбар | Сложнее масштабировать для длинных заголовков и мобильных режимов | Отклонено в пользу просторного Studio. |

## Последствия

- В модуле 1.3 верстка React-приложения строится по утверждённой композиции Studio.
- В модуле 1.4 дизайн-токены Tailwind / CSS Variables настраиваются согласно палитре Pearl.
- Контрастность пар цветов превышает требования WCAG AAA (минимальный контраст проверенной пары — 6.02:1 при норме 4.5:1 / 7:1).
- Шрифтовые файлы не бандлятся (используются системные шрифты Windows с безопасными fallback).
