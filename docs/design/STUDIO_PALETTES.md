# Studio — пять цветовых прототипов

Подготовлено 2026-10-14 по запросу пользователя. Базой служит Studio: верхняя навигация, просторная композиция и общий ряд метрик. **Конкретная палитра пока не утверждена.**

## Просмотр

[Общая галерея](studio.html) показывает пять вариантов рядом. Каждый вариант открывает интерактивный прототип с обзором, процессами, очисткой, журналом и настройками.

Все направления сохраняют тёмную тему. Для каждой палитры согласованы фон, поверхности, границы, основной и вторичный текст, акцент, фон акцентного блока и текст кнопки. Геометрия, типографика и функции общие; меняются только цветовые токены.

## Реализация

Палитры подключаются через `studio-palettes.css`, данные и маршруты — через общий `prototype.js`. Старый адрес `index.html#studio` открывает исходный Янтарь. Выбранная расцветка сохраняется в URL, а не в настройках будущего приложения. Переключение Control/Signal продолжает работать.

Прототип не читает системные показатели и не выполняет файловых операций. Финальная фиксация требует выбора пользователя; базовые модули приложения не отмечаются завершёнными.

## Проверки

- JavaScript проверен `node --check`.
- Для пяти desktop-палитр размеры окна совпали: около 823 × 1046 CSS px в проверенном окне. Горизонтального переполнения страницы нет.
- Пять палитр проверены при viewport 390 × 844: горизонтального переполнения нет; временный размер браузера сброшен.
- Проверены маршруты, переключение страниц, сообщение неподключённого сканера и отражение палитры в настройках.
- Полные снимки и галерея визуально просмотрены. Ошибок/предупреждений консоли при проверке не обнаружено.
- Статически рассчитан контраст следующих пар: основной текст / shell, вторичный текст / surface, вспомогательный текст / surface, текст кнопки / accent.
